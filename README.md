# 🐾 Animal Rescue Academy

**Animal Rescue Academy** is a high-polish, interactive educational English vocabulary game designed for young ESL/EFL learners (CEFR A1, ages 5–8).

🎮 **Play Online:** [https://maysaaaam-rgb.github.io/animal-rescue-academy/](https://maysaaaam-rgb.github.io/animal-rescue-academy/)

---

## 🌟 Pedagogical Framework

The game follows sound second-language acquisition principles, gradually scaffolding learning through 8 progressive missions:

$$\text{Recognition} \longrightarrow \text{Matching} \longrightarrow \text{Listening} \longrightarrow \text{Sight Words} \longrightarrow \text{Semantic Clues} \longrightarrow \text{Syntax/Sentences} \longrightarrow \text{Adaptive Spaced Review}$$

### 🎯 8 Scaffolded Missions
1. **Mission 1: Meet the Animals** — Phonetic pronunciation, model sentences, and interactive flashcards.
2. **Mission 2: Rescue the Animals** — Drag-and-drop & tap-to-match rescue enclosures with gentle retry hints.
3. **Mission 3: Listen and Find** — Auditory comprehension with dynamic distractors ($3 \to 4$ choices).
4. **Mission 4: Match Picture & Word** — Orthographic sight-word recognition.
5. **Mission 5: Animal Detective** — Semantic reasoning riddles using adjectives (BIG, FAST, WILD, STRIPED).
6. **Mission 6: Build a Sentence** — Syntax and sentence construction with karaoke spoken playback.
7. **Mission 7: Rescue Challenge** — Multi-skill safari ranger patrol combining all skills.
8. **Mission 8: Smart Review Mission** — Adaptive spaced practice dynamically targeting struggling words.

## 🌿 Core Features

- **🦁 10 Target Animals**: Lion, Elephant, Monkey, Rabbit, Cat, Dog, Tiger, Giraffe, Zebra, Bear.
- **🔊 Web Speech & Audio Synthesis**: Clear English speech ($0.85\times$ child-friendly speed) and procedural Web Audio SFX (positive chords, gentle retries, no external audio files required).
- **🧠 Adaptive Mastery Engine**: Tracks exposures, correct answers, mistakes, listening accuracy, and mastery states (`NEW`, `LEARNING`, `PRACTICING`, `MASTERED`).
- **📊 Teacher / Parent Dashboard**: Protected by an arithmetic gate (`5 + 3 = ?`); includes skill accuracy radar, detailed word matrix, *Unlock All* toggle, and printable *Rescuer Certificate*.
- **♿ Inclusive Accessibility**: Full support for Mouse, Touch, Drag-and-Drop, and Tap-to-Select modes across desktop, iPad/tablet, mobile, and interactive whiteboards.
